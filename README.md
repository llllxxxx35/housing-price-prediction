\# 波士顿房价预测



\## 任务

根据社区犯罪率、房间数、低收入比例等 13 个特征，预测房价中位数（MEDV，单位：千美元）。



\## 数据

\- 来源：UCI / Kaggle 公开波士顿房价数据集，505 行 × 14 列

\- 无缺失值，全部为数值特征

\- 目标列 MEDV 存在 50 的截断值（高价房被封顶）



\## 流程

1\. EDA：相关系数分析，LSTAT(-0.74)、RM(+0.70) 与房价相关性最强

2\. 划分训练/测试集（8:2）

3\. Baseline：线性回归

4\. 升级：LightGBM（200 棵树，学习率 0.05）



\## 结果

| 模型 | RMSE | R² |

|---|---|---|

| 线性回归 | 4.40 | 0.65 |

| LightGBM | 2.61 | 0.88 |



\## 关键发现

\- LSTAT（低收入人群比例）是最重要的特征

\- RM（房间数）次之，呈正相关

\- MEDV=50 的截断值导致高价段预测不准



\## 环境

Python 3.11, pandas, scikit-learn, lightgbm, matplotlib# 波士顿房价预测
